# Vue 3 za frontend

## Kontekst in opis problema

Frontend je enostranska spletna aplikacija, ki prikazuje skupine, stroške, stanja in predlagana nakazila. Razvijalec je pri frontend razvoju šibek, zato mora biti ogrodje čim lažje za učenje, hkrati pa dovolj zmogljivo za navigacijo, hranjenje stanja in klice API-ja. Katero ogrodje izbrati?

## Obravnavane možnosti

* Vue 3
* React

## Izid odločitve

Izbrana možnost: "Vue 3", ker ima od dveh ogrodij najpoložnejšo krivuljo učenja, njegove predloge pa so blizu klasičnemu HTML, kar je za razvijalca z malo izkušnjami s frontendom najlažji začetek. React zahteva več učenja zaradi JSX in izbire knjižnic iz širokega ekosistema. Uradne knjižnice Vue (Vue Router, Pinia) pokrijejo navigacijo in stanje, Vuetify pa ponuja gotove komponente za osnovni izgled.

### Posledice

* Dobro, ker je mogoče hitro začeti z razvojem uporabniškega vmesnika.
* Dobro, ker gotove komponente Vuetify zmanjšajo potrebo po lastnem oblikovanju.
* Slabo, ker ima Vue manjši ekosistem in skupnost kot React, zato je za nekatere probleme manj gotovih rešitev in virov.
